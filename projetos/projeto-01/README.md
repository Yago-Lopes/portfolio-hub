Portfólio Acadêmico — Bootcamp I

Descrição

O Portfólio Acadêmico é um projeto web desenvolvido para apresentar informações sobre o autor, organizar projetos acadêmicos e demonstrar conhecimentos iniciais em desenvolvimento web. A página foi criada com foco na simplicidade, organização e acessibilidade, permitindo que outras pessoas conheçam o projeto e acessem o repositório no GitHub.

Objetivo

Aplicar, na prática, os conceitos de desenvolvimento web, controle de versão e documentação de projetos. O trabalho também tem como objetivo desenvolver habilidades de organização de arquivos, utilização do GitHub e publicação de páginas estáticas na internet.

Tecnologias utilizadas

HTML5: estruturação do conteúdo da página.

CSS3: estilização e organização visual do portfólio.

Git: controle de versão e registro das alterações.

GitHub: hospedagem do repositório e gerenciamento dos arquivos.

GitHub Pages: publicação do site na internet.

Como visualizar o projeto

Acesse o site publicado pelo GitHub Pages:
https://yago-lopes.github.io/portfolio-hub/

Para consultar os arquivos-fonte, acesse o repositório:
https://github.com/Yago-Lopes/portfolio-hub

Abra o arquivo index.html para consultar a estrutura da página e o arquivo style.css para visualizar os estilos utilizados.

Aprendizados

Durante o desenvolvimento, foram praticados conceitos de estruturação de páginas com HTML5, estilização com CSS3, organização de arquivos, documentação em Markdown e controle de versão com Git e GitHub. Também foi possível compreender o processo de publicação de um site estático utilizando o GitHub Pages.

Status

Concluído — Versão 1.0

A versão inicial do portfólio foi desenvolvida e publicada. O projeto poderá receber futuras melhorias visuais, novos conteúdos e a inclusão de outros projetos acadêmicos.
