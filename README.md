- Organizar projetos acadêmicos e pessoais.

## Tecnologias
- HTML5
- CSS3
- Git e GitHub

## Estrutura
- `index.html`: página principal.
- `style.css`: estilos.
- `projetos/`: documentação dos projetos.
- `docs/`: materiais complementares.
