# Roteiro de apresentação – 5 minutos

1. **0:00–0:40 | Introdução:** diga seu nome, curso e propósito do portfólio.
2. **0:40–1:30 | Estrutura:** mostre repositório, pastas e arquivos.
3. **1:30–2:20 | Documentação:** abra o README principal e um README de projeto.
4. **2:20–3:20 | Versionamento:** mostre commits e a tag v1.0, se criada; explique uma alteração real.
5. **3:20–4:20 | Publicação e LinkedIn:** abra o GitHub Pages e mostre o link no perfil.
6. **4:20–5:00 | Fechamento:** resuma aprendizados e próximos passos.

Grave a apresentação e substitua este texto pelo link real do vídeo quando estiver publicado.
